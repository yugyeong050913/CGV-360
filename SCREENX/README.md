# SCREENX

`CGV-360`을 사이트 루트로 배포하면 `SCREENX/`에서 상영관을 열 수 있습니다. `SCREENX`와 `2D` 폴더를 같은 레벨에 둡니다. 최적화 GLB, Three.js, 스타일과 글꼴은 `2D` 폴더의 파일을 공유합니다.

로컬에서는 `CGV-360`에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000/SCREENX/`를 엽니다.

3D 모델 [Low Poly Cinema](https://sketchfab.com/3d-models/low-poly-cinema-b7e7bdff0f0446b49c8c43643b160dd3), b000f, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
